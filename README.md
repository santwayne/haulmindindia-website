# HaulMind India — Marketing Website

Static single-page marketing website for **HaulMind India** (multi-branch LR / bilty transport software by Wayne E Solutions).

## Files
- `index.html` — complete single-page website
- `styles.css` — responsive layout, hover and motion effects
- `script.js` — mobile navigation and 3D tilt interaction
- `assets/` — place local images/video here

## Preview
Open `index.html` in a browser. No build step needed — deploy the folder as-is to any static host (Nginx, S3, Vercel, etc.).

## Before launch
- Demo button opens an email to `hello@wayneesolutions.com` — change if needed.
- Hero video and photos load from Pexels/Unsplash; replace with local brand assets in `assets/` for production.
